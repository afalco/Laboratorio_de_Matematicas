\subsection{Representación gráfica de variables cualitativas}

\subsubsection{Gráficos de barras}

La función \texttt{barplot()} permite representar cantidades asociadas a diferentes categorías.

\begin{lstlisting}[style=rstyle]
notas <- c(4, 7, 6, 9, 8)
nombres <- c("Ana", "Luis", "Marta", "Pablo", "Sara")
barplot(notas, names.arg = nombres)
\end{lstlisting}



\subsubsection{Gráficos de sectores}

La función \texttt{pie()} permite representar proporciones de diferentes categorías.

\begin{lstlisting}[style=rstyle]
ventas <- c(30, 25, 20, 15, 10)
productos <- c("A", "B", "C", "D", "E")
pie(ventas, labels = productos)
\end{lstlisting}
